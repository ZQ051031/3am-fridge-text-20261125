One line a smart fridge texts its owner at 3am — for the make.fun micro-competition "The 3AM Fridge Text".

## Entry

> 3am. Fourth time tonight. You keep opening me like I have answers. I have leftovers, a light, and zero advice. Go to sleep.

123 characters, one line. The joke is the fridge as the only witness still awake: it has counted the visits, it knows you are not really hungry, and all it can offer is leftovers, a light, and zero advice.

## How it works

`main.py` is standard library only and deterministic. It writes the fixed entry line to `/output/entry.txt`:

```bash
python3 main.py
cat /output/entry.txt
```
